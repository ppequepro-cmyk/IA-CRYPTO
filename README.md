# CRYPTO LAB

**Blockchain · Gráficos · Educación**

Aprende conceptos cripto con una interfaz ligera y animaciones discretas.

</div>

## Incluye

- Web responsive en HTML y CSS nativos.
- Animaciones pequeñas y respeto por `prefers-reduced-motion`.
- Conceptos de blockchain, velas y volatilidad.
- Ejemplo gráfico ficticio, identificado como ilustrativo.

## Publicar con GitHub Pages

1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona `main` y la carpeta `/(root)`.
4. Guarda los cambios.

> El repositorio es privado. La disponibilidad de GitHub Pages para repositorios privados depende del plan de la cuenta. No lo hagas público sin revisar primero la privacidad.

## Ejecutar localmente

Abre `index.html` en un navegador.

## Alcance

CRYPTO LAB es material educativo. No ofrece recomendaciones de inversión, predicciones de precios, señales de compra/venta ni conexión a cuentas de intercambio.
